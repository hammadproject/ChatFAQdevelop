## Overview

ChatFAQ is an AI-powered FAQ and customer support platform designed to help businesses create intelligent chatbot experiences. It provides a complete system for managing FAQs, knowledge sources, conversations, and automated AI responses.

The platform includes an admin dashboard for managing chatbot settings, a customer-facing chat widget, and an AI knowledge system that helps deliver accurate answers based on stored information.

## Features

- AI-powered chatbot for automated customer support
- FAQ and knowledge base management
- Admin dashboard for configuration and monitoring
- Interactive chat widget integration
- AI-based knowledge retrieval system
- Conversation management
- Responsive user interface
- Multi-language support

## Technology Stack

- Frontend: Vue.js / Nuxt 3
- Backend: API-based services
- AI: Retrieval Augmented Generation (RAG)
- UI Framework: Element Plus
- Storage & Configuration: Environment-based setup

## Project Structure

- Admin Dashboard: Manage chatbot, FAQs, and settings
- Backend Services: Handle APIs and application logic
- Chat Widget: Customer-facing chatbot interface
- AI Module: Processes knowledge and generates responses

## Installation

1. Install project dependencies.
2. Configure environment variables.
3. Start the development server.
4. Open the application in the browser.

## Usage

Users can configure the chatbot, add knowledge sources, manage FAQs, and provide AI-powered support through the integrated chat interface.
